# Milan The Musafir (MTM)

Affiliate product catalogue for the Milan The Musafir travel/road-trip brand (https://milanthemusafir.com). Not an e-commerce store: no cart, checkout or prices. Each product card is an image plus a button that sends the visitor to the retailer (Amazon now, Flipkart later). `PRD.md` has the full requirements and roadmap; read it before adding features.

## Stack

Next.js 16 (App Router, Turbopack), React 19, TypeScript (strict), Tailwind CSS 4, `@vercel/analytics`. Deployed on Vercel. Import alias `@/*` maps to the repo root, though existing code uses relative imports.

## Commands

```bash
nvm use 22          # Next 16 needs Node >= 20.9; the machine default is 18 and `next dev` refuses to start
npm run dev         # http://localhost:3000
npm run build && npm start
npm run lint
```

There is no test suite. `test.js` is an empty stub, not a test.

## Layout

- `app/page.tsx` - home page (server component). Reads `?q=` and `?category=` search params and filters `products` in memory.
- `app/layout.tsx` - metadata, fonts, Vercel `<Analytics />`.
- `app/privacy-policy/page.tsx`, `app/not-found.tsx` - other routes. The footer links a Terms of Service page that does not exist yet.
- `components/Header.tsx` - client component: logo, category nav, search box, mobile menu.
- `components/ProductGrid.tsx`, `ProductCard.tsx`, `Footer.tsx`.
- `data/products.ts` - the whole catalogue as a typed array (`Product`: `id`, `name`, `image`, `category`, `amazonUrl?`, `flipkartUrl?`, `featured?`, `tags?`). Adding a product means adding an entry here and an image in `public/products/`.
- `public/` - `banner.jpg`, `brand-logo.png`, `products/*` images.

## Conventions and gotchas

- Header nav links are hard-coded (`Car Accessories`, `Gadgets`, `Apparel`) in two places in `Header.tsx` (desktop and mobile).
- Category filtering in `app/page.tsx` is a fuzzy hack: "Car Accessories" matches any category containing "car"; "Gadgets" matches categories containing "creator". Product categories in the data are inconsistent (`Car Accessories`, `Car Essentials`, `Camera`, `Electronics`, and lowercase `gadgets`), so the Gadgets tab misses Camera and Electronics items, and Apparel has no products. Normalize categories before building on this.
- Affiliate URLs are `link.amazon/...` short links. Keep them as given; do not rewrite them or invent URLs.
- Do not show prices and do not copy assets or branding from the reference site (pukkiofficial.com); the PRD forbids both.
- `next.config.ts` turns image optimization off in development (`unoptimized`) and uses a 30-day cache TTL in production, so image changes show instantly locally but are cached on Vercel.
- `.env` contains only `NODE_ENV=local`, which is not a standard value; do not rely on it. Never commit real secrets.
- `AGENTS.md` is regenerated by `next dev`. Next 16 has breaking changes versus older versions, so check `node_modules/next/dist/docs/` before using an API from memory.

## Workflow

- Flow per the PRD: local, then GitHub, then Vercel auto-deploys the latest pushed commit to milanthemusafir.com (the PRD says `git push origin main`). The checked-out branch is currently `features`. Commit messages are short lowercase phrases ("add products", "favicon").
- The `origin` remote URL has a GitHub personal access token embedded in it (visible in `git remote -v`). Never print or copy it; it should be rotated and the remote switched to a plain https or ssh URL.
- Verify UI changes in a browser (home page, `?category=...`, `?q=...`, mobile width), not just by building.
